# macOS 截图识别

macOS 11 或更新版本可使用原生框选层、系统截图与 Apple Vision 本地文字识别。Windows 截图 OCR 尚未开放，原有选区、剪贴板和输入翻译保持可用。无需安装 Python、下载独立 OCR 模型或配置图像服务商。

## 使用

1. 右键悬浮入口，点击“截图翻译”；或按 ⌥⇧O。也可在输入页执行 `/ocr`。
2. 首次使用时按系统提示授权“屏幕与系统音频录制”。若被拒绝，在“系统设置 → 隐私与安全性”中找到该权限并允许 LingoSofa，按系统要求重新打开应用后重试。应用启动时不会请求截图权限。
3. 在目标页面拖动框选需要识别的文字。按 Esc 取消框选，保留原界面和输入草稿。框选等待超过 90 秒会结束任务。
4. 框选完成后，在本机识别并直接开始翻译，默认贴在截图区域下方；空间不足时翻到上方。点击 Ask 可展开集中面板，围绕识别文字继续提问。

“截图翻译”和 `/ocr` 是主动翻译操作：框选完成后识别的文字会发送给默认模型并保存到对应会话。图片留在本机，识别内容不会被当作应用命令执行。

## 译文位置与快捷键

“设置 → 翻译偏好 → 划词与 OCR 译文位置”可选“原文下方 · 贴合显示”或“悬浮栏 · 集中面板”。默认使用原文下方；设置保存在本机。截图位置固定在本次框选区域，不跟踪原应用后续滚动；重新框选可更新位置。

- ⌥⇧S：划词翻译，使用默认样式。
- ⌃⌥⇧S：划词翻译，临时使用另一种样式。
- ⌥⇧O：截图 OCR 翻译，使用默认样式。
- ⌃⌥⇧O：截图 OCR 翻译，临时使用另一种样式。

以上组合均可在“设置 → 快捷键”修改，标签会显示各组合当前对应的样式。另一种样式的快捷键不会修改默认设置；旧版自定义组合保留，新增默认键若与其冲突会选择未冲突的备用组合，以设置页实际显示为准。Windows 保留选区翻译与两种样式的快捷键，不注册 OCR 组合。

`/ocr below` 可单次指定原文下方，`/ocr panel` 可单次指定集中面板，同样不改默认设置。

## 范围与限制

- 优先识别系统支持的简体中文、繁体中文与英文，保留识别行的顺序；不自动修正拼写，不承诺复杂表格、多栏排版、代码缩进和手写识别质量。
- 区域上限为 1600 万像素，PNG 文件上限为 64 MiB；结果最多 5000 个字符且不超过 15000 UTF-8 字节。超限提示重新缩小区域，不静默截断文字或缩小图片。
- OCR 在独立本机进程中执行，识别超过 20 秒会终止。新全局快捷键操作和退出应用会取消任务；迟到结果不能覆盖已切换的页面。
- 空白、模糊、受截图保护的画面可能无法识别；失败不会使用旧截图或自动切换云 OCR。

框选使用独立原生辅助进程，只捕获当前单个屏幕内选定区域，不支持跨屏拖选；屏幕权限与截图能力由系统决定。[Apple Vision 文字识别](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)使用本机框架。系统框选、真实屏幕权限、多显示器与受保护画面的最终验收须在实际设备操作；中英文图片的原生引擎回归不能替代这些验收。

## 临时数据

截图和识别进程的输出临时放在应用缓存目录的 `ocr/capture-*` 中，任务目录权限为仅当前用户可访问。完成、失败、取消、超时和正常退出会终止相关进程并删除临时目录；异常退出遗留目录会在下次截图任务开始时清理。图片不传给前端、翻译服务或 OMP 会话。

识别文字按普通翻译或 Ask 会话保存在本机；未发送的输入草稿只保留在内存。数据边界见[隐私说明](privacy.md)，文字会话见[会话指南](sessions.md)。
