## 更新交互与安装回归

- 使用实际 `UpdateSettings` 与插件样式进行浏览器交互测试，覆盖浅色、深色、320px 窄布局、主按钮悬停、下载中禁用、校验失败提示、重试、校验完成后才出现安装入口。
- 下载和执行前校验 SHA-256；仅接受固定项目 Release 的版本化 Windows EXE。校验失败不会执行安装。
- 实际 EXE 冒烟测试使用隔离 Discord Canary 资源和观察用启动器，确认启动时补丁已经写入；无效安装目标返回非零退出码，且不启动客户端。此测试已接入 Release Windows 打包步骤。
- 旧候选曾因根 ESM 包边界导致 Vencord CommonJS 加载失败，现由独立 `vencord/package.json` 隔离并有实际模块加载回归。
- Windows 首次启动曾超过 10 秒导致误报，启动等待改为 60 秒并覆盖延迟就绪回归；恢复连接会更新状态提示。
- 静默安装曾在安装前启动 Discord。现将自动启动放在组合安装成功之后，并显式报告失败退出码。新增 EXE 回归在旧候选上准确复现提前启动错误。
