# 订阅与账户登录

在输入或 Ask 窗口输入 `/login`（别名 `/subscribe`），用方向键选择服务商、Enter 登录。`/login 服务商ID` 可直接进入对应流程，Tab 可补全 `/login`。设置中的“模型与服务商 → 订阅账户登录”使用同一入口。

登录目录来自随包 OMP SDK 18.12.3 的登录注册表，并按其模型目录筛选；不维护 ChatGPT、Claude 等厂商白名单。目录包含订阅授权和部分使用密钥的服务商入口。服务商和登录方式名称以 SDK 为准，订阅是否包含模型权限仍由服务商决定。

| 登录方式           | 操作                                                                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 浏览器 OAuth       | 自动打开系统浏览器，完成授权；SDK 校验回调与 state，必要时可在应用中粘贴授权码或完整回调 URL。                                                         |
| 设备码             | 浏览器打开服务商的设备授权页面，按应用显示的代码授权，应用等待结果。ChatGPT/Codex 也提供单独的 `openai-codex-device` 入口。                            |
| 订阅密钥或其他交互 | 按服务商提示输入内容，Enter 提交；SDK 请求隐藏的输入使用密码框。                                                                                       |
| 浏览器会话登录     | 在应用新建的独立隐私窗口中登录，例如 Perplexity SSO。只读取该窗口中 SDK 指定名称的 Cookie，由 Rust 直接交回 worker，不返回主界面。关闭窗口会取消登录。 |

登录入口覆盖 OMP 目录中的 ChatGPT/Codex、Claude、Kimi Code、GitHub Copilot、Gemini CLI、Antigravity、Z.AI 和其他具备模型目录的登录服务商。对于仅有编码代理协议、当前桌面没有可用文本模型的服务商，登录列表会明确标注；登录成功不代表其代理协议已接入翻译工作流。自定义地址、本地免密模型、同一服务商多个账户仍未开放。

开始登录会结束当前模型会话，未提交输入草稿保留；取消返回原命令。登录成功只保存账户，不自动替换默认模型，随后在模型选择器确认模型。已有 API Key 配置继续可用；同一服务商重新登录在成功保存后替换该服务商的凭证。尚未提交成功的授权取消或失败时保留原凭证；已完成保存的授权不会因随后关闭界面而撤销。

授权凭证与刷新令牌加密保存在 Rust vault 中。worker 使用 SDK 刷新授权，刷新结果经 Rust 持久化确认后才更新 SDK 内存状态。重启后从 vault 恢复；在“模型与服务商”移除该服务商凭证可从应用退出账户，不代表撤销服务商网站的授权。不会读取其他应用或浏览器已有账户。

自动检查覆盖 SDK 设备码交换的模拟响应、授权提示、取消、过期尝试、加密保存、重启恢复和令牌刷新持久化边界。真实账户授权、各服务商权限和限额、Windows 与 macOS 浏览器兼容性仍需逐项人工验收；不会为验证登录自动发起付费模型请求。
