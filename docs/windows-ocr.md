# Windows 本地截图识别

Windows 使用独立 Rust helper：Win32 单屏框选 → BitBlt 内存截图 → 随包 PP-OCRv5 mobile 检测/识别模型 → ONNX Runtime CPU → 既有翻译与 Ask。macOS 继续使用 Apple Vision，见 [macOS 截图识别](macos-ocr.md)。

## 使用与兼容边界

- 点击悬浮菜单的截图翻译，输入 `/ocr`，或按 `Alt+Shift+O`；`Ctrl+Alt+Shift+O` 临时使用另一种译文布局。六个快捷键可在设置中修改。
- 目标 Windows 11 x64，需要 [Microsoft Visual C++ 2015–2022 x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。无法载入时提供官方修复入口，不自动安装。干净机及缺失运行库的安装体验仍需验收。
- 启动时选择鼠标所在屏幕，只支持该屏幕内框选。跨屏区域明确拒绝，不悄悄裁切；Esc 取消。支持负屏幕物理坐标，使用 per-monitor DPI awareness；混合 DPI 与实际多屏仍需人工验收。
- 框选限时 90 秒，本地识别整体限时 20 秒，包含资源校验、模型加载和推理。ORT RunOptions 终止正在执行的推理，helper 独立硬截止覆盖无法及时中断的初始化；主进程另有整体截止和进程回收。
- 区域最多 **400 万像素，最长边 4096 像素**。最多 128 个文字块、1000 个候选轮廓；过长单行或推理张量超限也会拒绝，提示缩小区域，不截断文本。文字上限 5000 字符且不超过 15000 UTF-8 字节。
- 支持范围为清晰单栏简体中文、英文及混排。小字、拼写波浪线、艺术字体、竖排和复杂表格/多栏仍可能误识别；需校对原文。模型语言范围不等于产品均已验收，没有通用准确率保证。

图片仅在 helper 内存中存在，不写临时文件，不进入前端、OMP 或云端，也不修改剪贴板。识别成功后沿用主动翻译行为，**文字立即发送给当前默认模型**并按普通会话保存；本地 OCR 不代表翻译离线。结果可进入 Ask。取消、超时、失败或退出会回收 helper；Windows Job Object 在主进程退出时终止该 helper，迟到结果不能覆盖新任务。详见 [数据与模型请求](privacy.md)。

## 模型与处理流程

默认只部署 PP-OCRv5 mobile，不静默回退到 Windows.Media.Ocr、其他引擎或云 OCR。系统 OCR 语言包和 MSIX 包身份不是本链路前提；不要求 Python、Paddle、GPU、CUDA 或 DirectML。

检测图按最长边 960 缩放并对齐到 32，DB 轮廓评分、扩张和四边形映射后，识别裁图始终来自原始像素（小图可放大），避免把大屏小字从已缩小的检测图中裁出。透视校正后按高 48 归一化，有限分组决定行宽填充，再逐行推理控制内存；CTC 使用官方匹配字典解码并恢复行序。没有词表替换、LLM 纠错或删除中英空格的文本修补。复杂段落版面分析不在首版范围。

检测、识别、字典和 ONNX Runtime 1.31.0 CPU win-x64 的固定官方来源、版本及 SHA-256 位于 [编译资源清单](../crates/ocr-helper/assets.json)。预期值编入 helper；随包 `provenance.json` 仅供查看，不能替换信任根。资源缺失、篡改或模型形状不符会明确失败，提示重新安装完整应用，不关闭校验继续识别。

资源仅在构建阶段下载，缓存位于 `.cache/ocr-assets`；运行时不联网下载。Windows 安装资源必须包含两个模型、字典、ORT DLL、来源清单和许可证。代码参考 RapidOCR 的预后处理约定，其 runner 不进入产品；模型与参考实现为 Apache-2.0，ORT 为 MIT，完整声明见 [OCR 第三方说明](../third-party-notices/ocr.md)。实际分发还需保留依赖的 notices。

## 检查与待验

`npm run check` 包含真实原生引擎的小字号/红色波浪线/中英混排、大字号、1920 宽小字、空白、损坏与超限输入回归；保留大小写、标点和空格计算字符错误，不能用单个子串证明质量。几何回归覆盖大轮廓与退化四边形，进程回归覆盖实际 ORT 中断、硬截止单 JSON 响应及资源篡改拒绝。

可运行 `powershell.exe -NoProfile -File tests/windows-ocr.ps1` 检查 helper、固定图片、合成 GDI BitBlt 和空白拒绝。合成 GDI 自测只捕获自身测试表面，不读取用户桌面，不能替代真实拖拽、Esc、屏幕切换、受保护画面、混合 DPI、干净机 NSIS 安装与新引擎的用户复验。单个固定样本通过也不能代替完整质量数据集。当前兼容状态见 [验收边界](acceptance.md)。
