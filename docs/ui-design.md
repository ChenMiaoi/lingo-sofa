# 内嵌双语与轻量入口

日期：2026-10-14。依据用户确认的网页/Discord 静态参考图与“悬浮入口 + 轻量菜单”选择实施；静态草图不作为真实验收。

## 阅读主体

单段或段内选区翻译直接插在对应原文下方，继承网页字体和颜色，不套译文卡片、不替换原文。整页模式逐段应用，只调度可见正文及附近内容；链接、内联代码、代码块与输入框保持原有结构。段落修改、隐藏或删除会清除失效译文；暂停保留已完成译文，中止未完成任务，晚到结果不会插回。跨段选区、复杂非正文结构可能降级为明确错误，不能宣称任意布局均支持。

## 网页入口

扩展主按钮为“在页面中打开控制”，打开时不发送正文。获准网站自动模式或手动启用后出现 44px 页边入口，可拖动吸附两侧、方向键上下移动、Escape 收起。280px 轻量面板只有目标语言、翻译主操作、已发现段落进度；更多操作才提供恢复、解释 / Ask Pi、设置与用量。

主操作随状态显示“翻译整页 → 暂停 → 继续翻译 / 恢复原文”；进度使用真实任务数量。段落悬停显示“译”按钮，可聚焦触发。Ask Pi 使用独立对话框，先显示只读选中上下文，点击提问才发送；关闭清理会话。发送前与回答返回时均验证上下文，原文变化不显示晚到回答。网页不能通过合成点击触发模型请求；内容脚本不持有 API Key 或账户余额。

设置、历史、预算、价格来源仍在辅助页面；保留浅深主题、392px 弹窗、1200px 设置页面、可见焦点和原生控件。

## Discord 入口

单条消息沿用消息悬停工具栏 / 右键菜单的翻译按钮，译文在原消息下方，回复、表情与代码仍属于原消息。纯代码块不发起翻译，混合消息仅发送代码块外的正文。成功译文的操作收在省略入口，日常不占据独立卡片。

频道边缘 44px 入口可拖动，展开后只显示语言、自动翻译此频道、只显示原文；更多操作才进入选区问答或独立配对/用量设置。自动模式按账号与频道授权，只处理新消息和可见历史，不读取全部历史。只显示原文会停止在途工作，恢复已缓存译文不重复请求。

控件通过 Vencord 的 `chatBarButton` 接口在宿主 React/store 就绪后挂载；没有可用输入栏的只读频道可能不显示悬浮入口，消息菜单作为备用。此限制仍需真实只读频道验证。选区问答保持选中范围，校验完整原消息用于检测编辑，不将完整原文自动扩大发送。输入框不被替换，不自动发送草稿。

- `layout.spec.ts` 检查浅深色、宽/窄布局和键盘顺序；截图人工检查。导航点击至第二次动画帧的本地反馈样本另行记录，不能代表模型延迟或读屏。
- `stress.spec.ts` 使用实际 MV3、1,000 段和 100 次 SPA 替换检查无重复节点、代码保持与停止清理，详见总验收。
- 可选 `public-page.spec.ts` 在真实 LLVM 文档网页插入 27 处译文，恢复前后比对 99 个代码块、803 个链接、29 个输入控件完全一致；本地模拟模型，只验证布局与恢复，不证明模型质量。
- 原 `/Applications/Discord.app` 的 LingoSofa 服务器已验证悬浮入口、展开/收起、真实 DeepSeek 下方译文、隐藏/恢复、编辑失效清理与新译文、当前测试频道自动翻译新消息和删除清理，见 [客户端记录](discord-acceptance.md)。未输入任何开发者控制台命令。

VoiceOver/NVDA、低视力缩放、只读频道、多账号、长频道虚拟滚动与其他系统继续保留为待验收；键盘检查不能代替读屏。检查截图在被 Git 忽略的 `.cache/ui/`，不包含在公开源码中。
