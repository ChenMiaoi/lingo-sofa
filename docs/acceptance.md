# 兼容范围与待验项

本文维护已知兼容范围和仍需验证的能力。已有检查仅覆盖对应平台和限定场景，不代表所有应用、版本或设备均兼容。自动回归以当前 CI 结果为准；W0–W4 的完整门槛见 [阶段验收计划](windows-acceptance-plan.md)。

## Windows

- 记事本、开启可访问性的独立 VS Code 和 Discord 消息正文已有选区翻译、来源滚动后收起、Ask 冻结上下文的限定场景验证。
- 浏览器正文选区仍未通过人工验收；步骤和离线样文见 [浏览器手动验收](browser-manual-acceptance.md)。不能用 DOM 检查、剪贴板翻译或 Discord 的结果替代。
- 输入翻译与独立新问题复用 Ask 面板。真实中文输入法候选确认、新问题的真实模型调用仍需专项验收；合成输入事件和模拟供应商回归不能替代。
- 全局快捷键支持改键、冲突提示和持久化；干净机安装/卸载、WebView2 缺失路径、多显示器及混合 DPI 仍待验证。

重测 Discord 时只读取已有消息正文，问题输入 LingoSofa 窗口；不得发送、回复、转发消息或添加反应。

## macOS

Apple Silicon 已验证应用启动、悬浮入口、菜单、输入面板、Enter 提交、Esc 返回和未配置账户提示；源码与独立 worker、凭证存取、进程回收和真实模型链路有本机验证。

跨应用 Accessibility 选区、真实键盘全局快捷键、多显示器布局仍待人工验收；Intel 的实际运行结果以对应 CI 和设备验收为准。权限与平台配置见 [开发指南](development.md#macos)。

## 模型与发布边界

当前桌面可从随包 oh-my-pi 目录配置多个 API Key 服务商并选择默认模型，旧 DeepSeek 配置保留。自动检查覆盖多服务商凭证隔离、模型路由与重启恢复；新增供应商的真实网络、账户权限和桌面视觉仍需人工验收。DeepSeek 真实链路已有流式、取消、排队、双路并发、压缩、凭证重开和用量恢复的限定场景验证。取消后供应商计费可能未知；缺失用量不能按零计。合成 OAuth 探针不代表真实 OAuth 授权通过。

真实 OAuth、其他供应商的真实请求、免 Key 引擎、同一服务商多账户、截图 OCR、历史清除、常驻资源预算、完整依赖许可证审计及签名发布仍需实现或专项验证。OCR 的候选与准入条件见 [OCR 方案](windows-ocr.md)。当前安装包未签名；macOS 尚未公证，不作为正式发布包。

## 如何记录验收

按 [开发指南](development.md) 执行自动检查；跨应用、输入法、安装和多屏场景须实际操作并观察。记录代码版本、平台与应用版本、复现步骤、实际结果和必要截图。未执行、失败和通过应分别注明。

本机报告保存在被忽略的 `.cache/`，CI 报告保存在 workflow artifacts，结果摘要放在提交或 PR 中。只将会影响后续使用的兼容边界和待验项更新到本文，不在仓库累计每次运行的日志、哈希或测试数量快照。
