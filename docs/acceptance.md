# 兼容范围与待验项

本文维护已知兼容范围和仍需验证的能力。已有检查仅覆盖对应平台和限定场景，不代表所有应用、版本或设备均兼容。自动回归以当前 CI 结果为准；W0–W4 的完整门槛见 [阶段验收计划](windows-acceptance-plan.md)。

## Windows

截图 OCR 使用原生单屏框选、内存像素捕获和随包 PP-OCRv5 mobile / ONNX Runtime CPU，接入翻译、Ask、六个快捷键与菜单。要求 Visual C++ 2015–2022 x64 运行库，限制 400 万像素与最长边 4096。合成小字/中英混排回归不代表通用准确率、真实拖拽、多屏/混合 DPI、受保护画面或干净机通过；用户已在真实窗口确认限定场景的框选、长译文阅读及操作；其他窗口与专项仍需分别复验。见 [Windows OCR 使用与兼容边界](windows-ocr.md)。

- 记事本、开启可访问性的独立 VS Code 和 Discord 消息正文已有选区翻译、来源滚动后收起、Ask 冻结上下文的限定场景验证。
- 译文浮层使用不透明阅读卡片；用户已在密集正文背景确认 OCR 译文不透字、长译文可滚至末尾、按钮可用，完整译文与复制粘贴保留末尾，Esc 返回正常，Ask 原文来自当前 OCR 而非先前浏览器选区。窄窗及其他显示器仍需分别复验。模拟 IPC 只能验证界面，不能代替原生选区与窗口验收。
- Windows 可选择开启鼠标选中后自动翻译，默认关闭并保存开关；手动快捷键保持可用。来源应用需已在前景；从后台激活窗口同时拖选可能被忽略，重新选择即可。Chrome 普通正文的自动划词、手动快捷键与鼠标顺畅已有下述限定验收；双击选词、其他应用、多屏及混合 DPI 行为仍待人工验收；仅键盘选区和 macOS 不自动触发。开关开启和关闭时，均需实际检查连续移动鼠标、跨显示器、拖选及翻译处理中无粘滞，关闭和退出及时解除监听。无 hook 的 Windows 消息泵回归只验证消息/控制事件唤醒及退出，不能代替真人鼠标体验验收。
- Chrome 样文的普通正文（BIRCH-562）已由用户确认自动划词与手动快捷键均出译文、鼠标移动顺畅；普通/内层选段不混入相邻正文，页面及内层实际滚动后译文收起。WILLOW-908 的 Ask 原文仅含所选段落，回答正确，原网页滚动后冻结原文与回答保留；取消选区后手动触发会提示错误，不翻译整页或显示旧译文。此为限定场景确认，不能推为全部浏览器、问答和退出边界通过；剪贴板及其他专项仍须分别验收。步骤和离线样文见 [浏览器手动验收](browser-manual-acceptance.md)；DOM 检查、剪贴板翻译或 Discord 结果不能替代对应原生操作。
- 输入翻译与独立新问题复用 Ask 面板。真实中文输入法候选确认、新问题的真实模型调用仍需专项验收；合成输入事件和模拟供应商回归不能替代。
- 全局快捷键支持改键、冲突提示和持久化；干净机安装/卸载、WebView2 缺失路径、多显示器及混合 DPI 仍待验证。

重测 Discord 时只读取已有消息正文，问题输入 LingoSofa 窗口；不得发送、回复、转发消息或添加反应。

## macOS

Apple Silicon 已验证应用启动、悬浮入口、菜单、输入面板、Enter 提交、Esc 返回和未配置账户提示；源码与独立 worker、凭证存取、进程回收和真实模型链路有本机验证。

截图 OCR 已接入系统框选与 Apple Vision，并覆盖中英文图片识别、大小/损坏检查、进程取消/超时清理和校对输入回归；系统屏幕权限、实际框选与多显示器仍待人工验收，见 [macOS OCR](macos-ocr.md)。

跨应用 Accessibility 选区、真实键盘全局快捷键、多显示器布局仍待人工验收；Intel 的实际运行结果以对应 CI 和设备验收为准。权限与平台配置见 [开发指南](development.md#macos)。

## 模型与发布边界

当前桌面可从随包 oh-my-pi 目录配置多个 API Key 或订阅账户服务商并选择默认模型，旧 DeepSeek 配置保留。自动检查覆盖多服务商凭证隔离、模型路由与重启恢复；新增供应商的真实网络、账户权限和桌面视觉仍需人工验收。DeepSeek 真实链路已有流式、取消、排队、双路并发、压缩、凭证重开和用量恢复的限定场景验证。取消后供应商计费可能未知；缺失用量不能按零计。订阅登录目录和交互已接入，自动检查覆盖模拟 SDK 设备码交换、取消、凭证保存和恢复；合成 OAuth 探针不代表真实 OAuth 授权通过，逐服务商验收边界见[订阅登录指南](subscription-login.md)。

真实 OAuth、其他供应商的真实请求、免 Key 引擎、同一服务商多账户、Windows OCR 的跨设备兼容与真实框选、历史清除、常驻资源预算、完整依赖许可证审计及签名发布仍需实现或专项验证。OCR 的候选与准入条件见 [OCR 方案](windows-ocr.md)。当前安装包未签名；macOS 尚未公证，不作为正式发布包。

应用更新已接入后台检查、设置内下载和手动安装重启，以及带 updater 签名的草稿发布流程。真实发布包的跨版本安装、系统签名、公证和三平台重启恢复仍待验收，详见[应用更新](updates.md)。

## 如何记录验收

按 [开发指南](development.md) 执行自动检查；跨应用、输入法、安装和多屏场景须实际操作并观察。记录代码版本、平台与应用版本、复现步骤、实际结果和必要截图。未执行、失败和通过应分别注明。

本机报告保存在被忽略的 `.cache/`，CI 报告保存在 workflow artifacts，结果摘要放在提交或 PR 中。只将会影响后续使用的兼容边界和待验项更新到本文，不在仓库累计每次运行的日志、哈希或测试数量快照。
