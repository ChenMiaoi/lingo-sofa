# 翻译引擎与问答模型

LingoSofa 的双语翻译支持必应、谷歌免 Key 引擎和现有大模型翻译。浏览器和 Discord 都支持三种选择，Ask 使用独立的默认模型。

## 默认行为与配置

- 浏览器首次使用默认直接连接翻译服务，无需安装本地助手或填写模型 Key。首次在「翻译偏好」选择引擎时授权其网络访问；已授权所有网页访问的浏览器也覆盖这些地址。
- 未配置模型凭证时，默认使用必应。已有 API Key、订阅或启用 Pi 认证的旧助手配置保留大模型翻译。
- 引擎选择会保存在本机。添加供应商、修改 Ask 默认模型和重新启动客户端不会覆盖已经选择的免 Key 引擎。
- 读取已保存的模型配置不访问模型供应商。模型账户不可用、模型列表读取失败或仍在加载时，仍可选择免 Key 引擎；切换不会删除模型账户或更改 Ask 默认模型。列表读取失败会明确提示，不将未知配置显示成已选择大模型。
- 浏览器「翻译偏好」配置翻译引擎，「问答设置」配置问答模型。模型账户与默认模型统一由助手管理；连接助手时两端共用引擎。未连接时浏览器可独立使用免 Key 翻译，不保存另一份模型账户。
- 选择大模型翻译后，可继续使用原有账户、上下文、模型能力和用量统计。Ask 始终需要自己的模型账户，不通过普通翻译服务回答问题。
- 页面与频道的悬浮控制也可以切换免 Key 引擎和当前供应商的模型。切换失败会保留原配置，运行中的翻译完成后才能更改助手引擎。

## 数据与执行

必应请求发送到 `https://edge.microsoft.com/translate/translatetext`，谷歌请求发送到 `https://translate.googleapis.com/translate_a/single`。两种实现都不包含共享 API Key，不提取网站账户凭证或登录 Cookie，也不依赖原站网页 DOM。只发送待翻译正文及目标语言，不发送 Ask 上下文或模型 Key。

这些是在线服务的网页翻译通道，不能保证永久可用或没有服务端限制。失败会提示用户稍后重试或手动切换，不自动向另一供应商发送内容，也不会自动转到付费模型。

共享核心注入翻译客户端，保持对浏览器、Discord 和 Node 的独立性。免 Key 适配器通过宿主注入的网络接口执行；浏览器在后台运行，Discord 通过已认证的本地助手执行。网络请求有超时和取消约束，文本按服务负载分批，响应数量与内容经过校验。

代码、公式、链接地址、Discord 提及和明确保护的片段保留在本机；Markdown 标签中的正文可以翻译，结构由本机重组。术语表在可翻译正文中应用，匹配区分大小写。由于格式片段会拆开处理，普通引擎的上下文与术语灵活性不同于大模型翻译。

缓存按引擎隔离。普通翻译记录字符数和耗时，显示「免 Key 翻译」与零模型费用；Tokens、TPS 与模型缓存计量不适用。免费记录不会被计入未知模型消耗。

## 验证范围

自动测试覆盖引擎选择、凭证独立、缓存隔离、响应异常、限流、不自动重试、取消、长 Unicode 文本、Markdown 与受保护内容。Bridge 集成测试同时使用真实 Discord 客户端协议和已授权浏览器来源，验证共享配置及重启保留；外部翻译响应使用固定测试数据。

浏览器测试加载实际 MV3 构建，检查无 Key 设置、两种引擎的网页译文、添加 Key 后保留引擎、独立 Ask 配置、窄屏及明暗主题。真实在线连通性另以非敏感示例文本检查，不把固定测试响应当作外部服务连通性证据。自动组件与 Bridge 测试不能替代已安装 Discord 中的用户验收。

设置环境变量 `LINGO_SOFA_LIVE_TRANSLATION=1` 后运行 `tests/e2e-browser/free-translation.spec.ts` 中的首项测试，可改用真实在线服务验证同一浏览器流程。它仅发送测试网页的 “Hello world”，不需要模型 Key。普通测试默认使用固定响应，避免依赖外部服务状态。
