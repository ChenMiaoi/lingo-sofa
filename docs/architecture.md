# 正式桌面实现

2026-10-21。本文描述现有代码；[总方案](lingo-sofa-plan.md) 与 Windows 设计文档还包括未实现目标。

界面沿用 v3 的阅读与 Ask 工作流，按后续确认改为中性灰黑、半透明表面。设置参考 oh-my-pi 的紧凑列表组织：左侧名称、右侧当前值、弱化说明，保留桌面分类子页；模型、服务商与凭证使用对齐的设置行。设置首页默认聚焦首项，支持方向键选择与 Enter 打开，Esc 逐级返回。输入、Ask 与继续追问共用本机斜杠命令解析，导航命令直达设置子页，配置命令复用模型选择与偏好服务接口；未知命令不回退到模型调用。`/model` 在 launcher 内打开键盘模型选择器，按已配置服务商读取全部目录分页后在本机搜索；Esc 返回原命令，确认后复用 `select_model`。无凭证时使用同一浮层中的服务商选择、模型选择和密码输入步骤，调用 `save_provider` 成功后再选择模型，失败保留原默认模型；模型选择器不依赖设置导航。`/new` 通过 `new_session` 重置 Service 会话并递增桌面 epoch，清理原文、结果和草稿后返回 Input，旧 OMP 文件保留供 `/resume`，阻止旧选区任务回填。语言与置顶以字段补丁在 Service actor 中合并、持久化并确认，避免前端轮询间隔内连续命令覆盖彼此。Ask、输入、菜单与设置使用 Windows 原生 Acrylic，CSS 提供灰黑底色与细边框；系统未提供背景效果时仍可读取文字。输入面板为 620 × 324，编辑区随内容增长并在上限内滚动，不再使用固定的大文本框。[交互设计原型](design/desktop-v3/DESIGN-NOTES.md)保留阅读与 Ask 的设计约束，配色以当前实现为准。

```text
React → Tauri commands → Service actor → scheduler → Host → private pipes → Bun/OMP
                           ├─ SQLite settings
                           ├─ DPAPI credentials
                           └─ SQLite usage ledger
```

`crates/core` 不引用 Windows、Tauri、Node 或网络。`omp-client` 封装 Windows Job、IPC、凭证和账本；`app-services` 在专用线程拥有 Host，窗口线程只发送有界命令、读取无密钥快照。模型任务通过业务队列调度，保留优先级、TTL、会话串行、revision 淘汰和全局 2 个调用上限；压缩预留 2 个名额。

当前 UI 显示一个阅读会话。重新翻译取消旧任务并新建会话，追问复用当前会话。取消不代表零费用，断线不自动重发。压缩通过相同业务队列执行。状态每 120ms 拉取，只有当前会话的流式文本进入结果；隐藏再打开不重复发请求。

手动输入复用 Ask 的深色 launcher，输入模式支持多行原文和明确的翻译/新问题动作，结果复用 Ask 回答区域。`submit_new_question` 将新问题与继续追问区分，在同一准入命令内强制新会话；不继承之前的原文或翻译指令。选区和剪贴板翻译仍使用轻量译文浮层。

`apps/omp-worker/src/worker.ts` 是唯一生产入口，通过 SDK ModelRegistry 与认证元数据提供服务商、分页模型目录和原生协议。当前开放 API Key 和 SDK 订阅登录 + 已接入原生聊天协议的服务商；默认模型可切换，未保存选择时沿用 `deepseek/deepseek-flash`。模型目录读取随包 SDK 数据，不主动查询所有服务商接口；目录存在不代表账户已获授权，凭证与模型权限仍以实际请求结果为准。受限 SDK 默认关闭工具，Ask 可经 `/tools on` 启用内置文件与命令工具，Agent.beforeToolCall 中的单次确认门在执行前拦截，取消与超时拒绝；翻译任务关闭工具。项目资源、扩展发现、自动压缩、重试和回退仍禁用。多个服务商的 API Key 在 Rust vault 中独立保存；worker 握手只请求 Host 允许的账户标识，模型启用后仅将所选服务商凭证放入 SDK 内存认证存储。SDK 原生流式调用仍经过统一的并发准入、用量终态提交与取消通道，模型网络目的地限定为所选 SDK 模型地址及其凭证声明的服务地址，拒绝重定向。登录/刷新使用独立授权上下文，仅允许 HTTPS，由所选 SDK 登录流程决定地址，不接受前端任意 URL。登录状态只包含 URL、提示和结果，不包含令牌；特殊浏览器会话由隔离 WebView 与 Rust 传递 Cookie，远程窗口无主窗口命令权限。详见[订阅登录](subscription-login.md)。切换默认模型或修改凭证结束旧 worker 和会话，后续请求使用持久化选择；不自动回退至其他服务商。进程环境被清理，不读取开发 `.env`。模拟 HTTP、假 OAuth 和故障入口仅在 `tests/fixtures`。

Tauri 命令检查 `main` 窗口身份，不开放任意 URL、SQL、文件或进程执行；前端仅拥有拖动权限，CSP 禁止供应商网络访问。Ask 输出使用 React Markdown AST 渲染标题、列表、代码与表格，跳过原始 HTML，不加载图片或提供直接导航链接；工具结果按纯文本投影显示。剪贴板快捷键仅在按下时读取文本。桌面快捷键模块独立管理全局组合，保存于 `shortcuts.sqlite`；先验证和注册新组合，再提交 SQLite，成功后更新路由并释放旧组合。失败会撤销新注册并保留原设置；启动时逐项注册和报告，未启用项不影响其他入口。旧组合若释放失败也不再分发动作。默认 Alt+Shift+Space 唤出输入面板，重复唤出保留草稿；所有按键展示来自当前注册状态。

desktop v3 的边缘入口、译文浮层、Ask、输入和设置由 Rust Shell 控制窗口尺寸、位置和焦点。Alt+Shift+S 启动独立 `selection-helper.exe`，通过 UIA 只读取前台应用的非密码选区及矩形。首帧限时 1800ms，后续心跳限时 900ms；助手挂起时由 Job 回收。原窗口移动、选区变化或失效时收起译文并取消任务；已经主动打开的 Ask 保留原文，停止依赖旧锚点。几何计算有纯函数回归；应用兼容性按验收记录逐项说明，混合 DPI 尚未完成。macOS OCR 使用独立原生 `region-selector` 框选层和系统截图，临时 PNG 仅放在权限为 0700 的任务目录，再交给独立 `ocr-helper` 使用 Apple Vision 本机识别；20 秒识别截止、取消与退出会回收进程和临时文件。区域坐标回传主进程，识别后按主动请求直接翻译；默认在区域下方显示，可设置集中面板或用另一种样式的快捷键单次覆盖；图片不进入前端或 OMP。Windows OCR 尚未接入，详见 [macOS OCR](macos-ocr.md)。

取文会先验证焦点至来源窗口的祖先路径（最多 32 层），再沿该路径查找 TextPattern；拒绝密码或无法验证的路径，不扫描文档后代。已验证记事本、独立 VS Code 与 Discord 消息正文；浏览器未通过，混合 DPI 仍未验收。

数据根为 `%LOCALAPPDATA%/LingoSofa`：`credentials.sqlite` 保存用户范围 DPAPI 密文与 CAS revision；`settings.sqlite` 保存语言、置顶及独立的默认模型选择；`usage.sqlite` 保存不含正文/密钥的调用账本。OMP SessionManager.create/open 在同目录 `sessions/` 保存 JSONL；原文与来源是 OMP 自定义元数据，完整上下文、思考与工具结果由 OMP 持有。`sessions/current.json` 是当前会话指针，前端启动请求恢复，Rust 服务通过 OMP 重建上下文，Shell 恢复显示并移除旧锚点。`/new` 清除当前指针和显示，保留旧文件；新提交创建新会话。macOS 数据根为 `~/Library/Application Support/LingoSofa/`。账本发送前写入、终态幂等、崩溃恢复为未知，API Key 已知价格按 SDK 用量保存费用估算，订阅和无价格记录保持未知；独占控制防止两个 Host 互相覆盖。

worker 延迟启动，退出或父进程崩溃时由 Job 回收；重建不重放。应用不暴露本地 HTTP Bridge。Bun 编译 worker 和匹配 native addon 作为资源随 NSIS 分发。native addon 较大，不能宣称已完成轻量资源指标。

与规划的差距：尚无同一服务商多账户、免 Key 引擎、自定义服务地址、历史清除界面、Windows OCR、窗口位置恢复；UIA 和多屏 DPI 仍需原生专项验收。桌面数据不导入旧助手或 W0 账户。

参考：[Tauri 配置](https://v2.tauri.app/reference/config/)、[快捷键](https://v2.tauri.app/plugin/global-shortcut/)、[剪贴板](https://v2.tauri.app/plugin/clipboard/)。

会话历史、`/resume`、思考档位、工具单次确认与用量显示见[会话指南](sessions.md)。历史列表和显示投影经有界私有 IPC 返回，前端不获得任意文件路径；恢复只接受应用会话目录中的 ID，拒绝路径穿越与指向外部的符号链接。

Ask 回答视图按 OMP 的正文、思考、工具与状态栏层次组织：单个滚动区域承载 Markdown 和每次工具调用，起止事件按调用 ID 合并并提供短输出预览。追问框位于回答下方，费用明细是状态栏上的可关闭浮层；历史按需切换，流式更新尊重用户已滚动的位置。

后续 UI 与流程以项目锁定的 OMP 版本为主要参考，重点对照 `pi-tui` 的 composer、transcript 与 status-line，以及 `pi-coding-agent` 的命令和会话控制。保留正文优先、底部多行输入、斜杠命令、紧凑状态行、按需展开详情和键盘逐级返回的一致性；桌面侧继续保留原文上下文、划词翻译和显式进入 Ask 的流程。不要为了模仿终端布局增加始终展开的工具、费用或历史侧栏。

追问输入框从单行自动增高，达到五行后内部滚动；提示符与首行文字对齐。回答页的命令列表在输入框上方展开，正文与滚动位置保持挂载。生成期间输入区提供停止按钮，Esc 停止生成而不跳离回答页，已有草稿保留；命令展开时 Esc 优先关闭命令。非命令多行编辑保留上下方向键用于移动光标，Ask 动作选择可使用 Alt+方向键。

原生标题区域通过受限的 `drag_window` 命令移动窗口，按钮、输入框、链接与原文浮层不触发拖动。Windows 在窗口线程释放鼠标捕获并发送包含有符号屏幕坐标的非客户区拖动消息；其他平台使用 Tauri 拖动接口。置顶偏好保存后立即应用到当前窗口，不重置窗口位置。验收应同时检查真实系统缩放、拖动后的控件操作与跨应用遮挡关系；浏览器缩放不能替代系统 DPI 验收。

完整过程以 OMP 会话 JSONL 的活动分支为唯一来源，包含压缩前的历史轮次；不另存一份工具日志。`session.activity` 只读取已保存的提问、回答、思考和工具调用/结果，按 JSON 字节预算分块返回，并用内容版本校验阻止混合不同快照。服务层校验当前会话身份，生成期间不读取未完成快照。前端按会话与任务版本取消旧读取，加载失败可重试；当前回答自动恢复过程，“会话记录”按轮次展开完整内容。缺少结束结果的工具显示为已停止，恢复不会重新执行工具或恢复旧确认请求。旧版本已保存的 OMP 记录可直接读取；进程被强制终止前尚未写入会话文件的流式片段无法恢复。

回答代码块保留原始缩进，以独立滚动区域承载长代码，提供语言与行数、自动换行、展开和复制；表格采用固定表头及独立双向滚动，可展开全部行并复制为带引号转义的 TSV。复制回答使用完整恢复内容，代码复制不受换行显示影响。复制操作显示处理中、成功或可重试失败，原生剪贴板边界拒绝超过 4 MiB 或含 NUL 的内容，避免静默截断。轮询保持组件身份、展开状态、焦点及滚动位置。

代码高亮使用 lowlight 的语法树渲染 React 节点，不插入 HTML；采用常用语言集并按内容与语言缓存，未知语言及超过 100,000 字符的代码保留纯文本。行号为不可选择的装饰，可独立隐藏，换行后仍按源代码行计数。代码工具栏在展开阅读时固定；选区提供“复制选中内容”，并保留系统复制快捷键，代码选区复制不包含装饰行号。选中代码和切换阅读选项会暂停自动跟随。

回答定位提供 Ctrl+F / ⌘F 文本搜索，覆盖正文、代码、表格及完整记录中可展开的内容；Enter / Shift+Enter 与 F3 / Shift+F3 切换匹配，Esc 关闭搜索并返回原焦点。搜索为不区分大小写的字面量匹配，最多呈现前 1,000 处并标示上限，使用浏览器 Highlight API 着色，不改动 React 文本节点或用户选区。代码内 Ctrl+G / ⌘G 打开源行号跳转，验证范围并标记目标行。阅读状态按本机会话与回答区分，保存正文、代码和表格滚动、代码显示选项及记录展开状态；完整会话内容加载后恢复，生成期间不覆盖历史位置。WebView 本地存储仅保存位置和显示状态，不保存正文或搜索词，保留最近 120 项；存储不可用时仍可阅读。
