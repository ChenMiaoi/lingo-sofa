# LingoSofa v3 · 普通翻译模式

这版明确区分两种状态：

- **普通阅读 / 翻译模式**：不打开启动器。选中文字后，译文贴在该段下方，像一条临时阅读批注。
- **Ask 模式**：只有明确点击 Ask，才进入已认可的 v2 启动器；带入同一段已选文字。

## 译文的形态

- 与原文左边缘对齐，尽量沿用选区的列宽；短选区与过宽选区限制到适合阅读的宽度，并限制在屏幕工作区内。
- 原文与译文保持上下关系，不放到远侧弹窗。
- 译文按内容调整高度，达到高度上限后可滚动阅读；正文不按三行裁切。独立阅读窗保留完整译文，不重新请求模型。
- 不加标题栏、语言工具栏、历史记录、聊天气泡或常驻输入框。
- 常驻显示完整译文、复制、Ask、收起操作，明确区分仍在生成与生成失败后的部分译文。
- 原文仍在原来的位置，译文是覆盖层，不是插入宿主文档的内容。

## 空间与生命周期

- 下方已有空白时，译文利用现有空白。
- 下方没有空白时，通用桌面浮层会遮挡后文。设计对照图明确展示覆盖，不假装把原文向下推。
- 基线设计：宿主滚动、窗口移动或几何位置失效后收起译文。用户重新选中即可再次翻译。
- 真正的行内重排，只能在具备受支持的文档集成、能修改其排版时实现。本方案不声称对任意桌面应用都能重排。

## 演示内容

1. 普通阅读：只剩小型边缘入口。
2. 选区下方翻译：轻量批注式译文。
3. 悬停操作：复制 / Ask / 收起。
4. 转入 Ask：沿用已选文字，保留 v2 的启动器视觉。
5. 空间不足：译文覆盖下一段的真实布局约束。

## 打开原型

打开 [交互原型](index.html)，无需联网或安装依赖。

- 顶部场景可切换固定设计状态。
- 阅读态可点击示例段落触发翻译，或使用页面下方“翻译示例段落”。
- 译文区域悬停可看到三个操作；点击 Ask 进入嵌入的 v2 启动器。
- Ask 中可输入、筛选动作、上下选择、Enter 执行固定示例；列表态 Esc 返回阅读。
- 页面下方有“模拟原应用滚动”和“模拟移动窗口”，均触发收起。
- 在示例画面上滚动也会触发收起演示，不代表原型连接了真实宿主窗口。
- 复制功能使用浏览器剪贴板；不允许时给出提示。

## 边界

这是一份 SVG 支撑的交互设计原型。普通模式的源文与选区为固定示例，Ask 的数据和结果也是固定演示。没有真实划词监听、OCR、模型调用、屏幕捕获、系统窗口监测或全局热键。

SVG 为设计示意，不是运行中的桌面应用截图；实际界面以当前实现为准。
