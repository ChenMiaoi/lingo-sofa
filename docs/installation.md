# Windows 开发版安装与使用

目标 Windows 11 x64。需要系统 WebView2；NSIS 使用 Tauri 默认 WebView2 检测/引导安装方式。当前包未签名、未公开发布；干净机器和无 WebView2 环境仍须专项验收。

从源码构建见 [README](../README-zh.md)。正式安装包输出到 `target/release/bundle/nsis`，调试包到 `target/debug/bundle/nsis`。安装后在设置中填写自己的 DeepSeek API Key。

右键边缘入口或通过托盘打开设置，填写账户和目标语言。在其他应用选中文字后按 Alt+Shift+S 获取选区并翻译；该路径只支持提供 UIA TextPattern 选区的应用，已验证记事本、开启可访问性的独立 VS Code 和 Discord 消息正文，其他应用兼容性仍需专项验收。浏览器尚未通过，见 [手动清单](browser-manual-acceptance.md)。也可复制后按 Alt+Shift+T，按 Alt+Shift+Space 唤出输入翻译或独立提问，也可使用托盘。

输入翻译复用 Ask 的深色面板，粘贴多行文字后选择翻译或作为独立新问题提问。Enter 执行，Shift+Enter 换行，Alt+↑↓ 切换动作；结果在同一面板显示，可继续追问。新输入与新问题创建新会话，不引用之前的阅读原文。

译文浮层最多显示三行，悬停或键盘聚焦显示复制、Ask 和收起操作。Ask 保留原文；方向键选择操作、Enter 执行、Esc 返回阅读；输入法组合期间不提交。Ask 回答中可取消、复制和手动压缩，较短会话可能无需压缩。输入和设置面板顶部可拖动，窗口大小由当前模式管理。设置中“全局快捷键”可修改三项组合，使用 Ctrl 或 Alt 搭配字母、数字、Space 或 F1–F24。填写后点击“保存快捷键”，生效状态逐项显示；“恢复默认”只填回默认值，仍需保存。应用内重复组合会拒绝，系统占用或保留组合会提示，注册或持久化失败保留原设置。重启后重新注册保存的组合，如届时被占用则显示未启用，其他成功项继续工作。可从边缘入口或托盘打开设置修复。不会自动监听剪贴板变化或模拟复制。

数据位于 `%LOCALAPPDATA%/LingoSofa`。移除账户会删除当前加密凭证并停止 worker，用量历史保留。卸载不代表已确认清除数据；完全清理时先退出应用，再删除上述目录。旧助手、W0 和浏览器数据不自动导入。
