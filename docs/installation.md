# Windows 开发版安装与使用

目标 Windows 11 x64。截图 OCR 另需 [Microsoft Visual C++ 2015–2022 x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)；缺失时应用提供官方修复入口，不自动安装。模型随包提供，识别阶段无需联网或系统 OCR 语言包，见 [Windows OCR](windows-ocr.md)。需要系统 WebView2；NSIS 使用 Tauri 默认 WebView2 检测/引导安装方式。安装包从 [GitHub Releases](https://github.com/ChenMiaoi/lingo-sofa/releases) 下载。更新包具有 updater 签名；Windows 代码签名尚未配置，干净机器和无 WebView2 环境仍须专项验收。

从源码构建见 [README](../README-zh.md)。正式安装包输出到 `target/release/bundle/nsis`，调试包到 `target/debug/bundle/nsis`。安装后进入“设置 → 模型与服务商”，选择服务商并保存 API Key，再选择模型并点击“设为默认模型”。可配置多个服务商，每个服务商独立保存一份 API Key。服务商、模型名称和模型限制来自随包 oh-my-pi 目录；目录分批加载，可刷新或加载更多。订阅账户可输入 `/login` 或 `/subscribe` 登录，目录来自 OMP；支持浏览器授权、设备码、交互提示和独立浏览器会话，见[订阅登录指南](subscription-login.md)。云平台特殊凭证、本地/免 Key 模型、同一服务商多账户与自定义地址尚未接入。

右键边缘入口或通过托盘打开设置，填写账户和目标语言。设置使用输入翻译与 Ask 共用的导航窗口，首页按模型与服务商、翻译偏好、快捷键、关于与更新分类，选择分类后进入独立设置子页；也可点击输入或 Ask 页面中的设置图标进入。点击顶部返回或按 Esc 逐级返回；子页先回设置首页，再回原页面，保留尚未发送的输入、多行草稿、已选动作和继续追问内容，并恢复输入焦点。分类间切换也会保留未保存的快捷键编辑，仍需点击“保存快捷键”才生效。从边缘入口或托盘直接打开设置后，返回输入页面。开始新的阅读或输入会话时，旧草稿仍会清空。在其他应用选中文字后按 Alt+Shift+S 获取选区并翻译；该路径只支持提供 UIA TextPattern 选区的应用，已验证记事本、开启可访问性的独立 VS Code 和 Discord 消息正文，其他应用兼容性仍需专项验收。浏览器尚未通过，见 [手动清单](browser-manual-acceptance.md)。也可复制后按 Alt+Shift+T，按 Alt+Shift+Space 唤出输入翻译或独立提问，也可使用托盘。

输入与 Ask 窗口支持本机 `/命令`：输入 `/` 或 `/help` 查看列表，方向键选择、Tab 补全命令、Enter 执行、Esc 退出命令。补全只填写当前候选并添加空格，不执行命令；例如 `/mo` 后按 Tab 得到 `/model `。光标位于命令名中时补全保留已有参数，编辑参数时 Tab 保留原本的焦点导航行为，Shift+Tab 也仍用于反向移动焦点。输入法确认和 Shift+Enter 不执行命令。格式错误或未知命令只显示本机提示；命令本身不会进入模型会话；`/ask 问题` 只提交去掉命令前缀的问题正文。正文需要以斜杠开头时写 `//`，提交时保留一个 `/`。

| 命令                                                                                                       | 操作                                                                                                   |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `/settings`                                                                                                | 打开设置首页。                                                                                         |
| `/settings models`、`/settings preferences`、`/settings shortcuts`、`/settings updates`、`/settings usage` | 直接打开对应设置子页。                                                                                 |
| `/usage`                                                                                                   | 打开用量与费用；命令名不区分大小写，返回时保留输入草稿和 Ask 上下文。                                  |
| `/login [服务商]`、`/subscribe [服务商]`                                                                   | 订阅与账户登录；成功后返回模型选择，默认模型须单独确认。                                               |
| `/model`                                                                                                   | 在当前窗口搜索已配置服务商的模型，↑↓ 选择、Enter 切换、Esc 返回。                                      |
| `/model 搜索词`                                                                                            | 打开模型列表并按名称、ID 或服务商过滤（搜索词不含 `/`）。                                              |
| `/ask [问题]`                                                                                              | 携带问题时直接提交；独立输入创建新问题，Ask 中沿当前上下文追问。不带问题时准备提问，无需鼠标选择动作。 |
| `/new`                                                                                                     | 停止当前任务并保留旧会话历史，清空当前原文、结果和草稿，回到独立空白输入；保留模型与其他设置。         |
| `/model 服务商/模型ID`                                                                                     | 设置默认模型，须先配置服务商凭证；模型 ID 中的斜杠会保留。                                             |
| `/language en`                                                                                             | 修改翻译语言；支持 `zh/en/ja/ko` 或 `简体中文/English/日本語/한국어`。                                 |
| `/pin on`、`/pin off`                                                                                      | 设置 Ask 与输入窗口置顶。                                                                              |
| `/shortcuts`                                                                                               | 打开快捷键页。                                                                                         |

`/ask` 支持多行问题，保留正文内的空格与换行；正在生成或压缩时提示等待，不中断当前任务。提交失败保留命令草稿。不带参数的 `/ask` 在独立输入中选择“作为新问题提问”，在 Ask 中清空命令并等待输入问题，不发送请求。

不带参数的 `/language` 和 `/pin` 打开翻译偏好页。连续执行语言、置顶命令只更新各自字段，保存失败时保留原设置。`/model` 切换仍会结束当前会话；未配置凭证时，`/model` 在同一浮层中用 ↑↓/Enter 选择服务商与模型，再在密码输入框输入 API Key，Enter 保存并切换，Esc 逐级返回；不会跳转设置页。已配置服务商时直接显示模型列表，可用 Tab 聚焦“服务商”按钮后 Enter 浏览其他服务商。模型与服务商设置页仍可管理和移除凭证。

输入翻译复用 Ask 的深色面板，粘贴多行文字后选择翻译或作为独立新问题提问。Enter 执行，Shift+Enter 换行，Alt+↑↓ 切换动作；结果在同一面板显示，可继续追问。新输入与新问题创建新会话，不引用之前的阅读原文。历史会话可通过 `/resume` 搜索、方向键选择并按 Enter 恢复，重启后可继续当前会话；`/new` 保留旧文件。思考档位 `/thinking`、工具开关 `/tools` 和每次工具执行的键盘确认见[会话指南](sessions.md)。

输入、剪贴板与继续追问共用 15000 UTF-8 字节上限，约为 5000 个汉字；超长文本会提示缩短或分段，未发送的草稿保留。尚未建立模型会话时，围绕选区提问会合并原文和问题；合并后超限会单独提示原文过长。翻译偏好中的语言、置顶和译文位置分别保存，只有本地写入成功才确认；失败时显示提示并保留原设置。

译文浮层尽量跟随原文选区宽度排版，短选区和过宽选区会限制到适合阅读的宽度，窗口始终限制在屏幕工作区内。浮层按实际内容调整高度，达到高度上限后可用鼠标滚轮或聚焦译文后用键盘滚动，不再截断为三行。操作栏常驻显示“完整译文”、复制、Ask 和收起；点击“完整译文”可进入独立阅读窗，复用已有译文，不重新请求模型。完整阅读窗保留译文，来源滚动后仍可阅读，按 Esc 或“返回浮层”返回；来源位置已失效时则收起。生成中的译文和生成失败后的部分译文会分别提示状态。

Ask 保留原文；方向键选择操作、Enter 执行、Esc 返回阅读；输入法组合期间不提交。Ask 回答中可取消、复制和手动压缩，较短会话可能无需压缩。输入和设置面板顶部可拖动，窗口大小由当前模式管理。设置中“全局快捷键”可修改三项组合，使用 Ctrl 或 Alt 搭配字母、数字、Space 或 F1–F24。macOS 额外支持 Command/Cmd/Meta/Super、Option/Alt/Opt、Control/Ctrl，以及 ⌘、⌥、⌃、⇧ 符号（例如 `Command+Option+Q`、`⌘⌥Q` 或 `⌘+⌥+Q`）；可使用 Command、Option 或 Control 搭配上述按键。macOS 设置输入框使用 Command、Option 名称，并提供符号预览；菜单、边缘入口提示和面板内快捷键也显示对应符号。默认组合沿用原设置，显示为 ⌥⇧Space、⌥⇧S、⌥⇧T；Windows 行为不变。填写后点击“保存快捷键”，生效状态逐项显示；“恢复默认”只填回默认值，仍需保存。应用内重复组合会拒绝，系统占用或保留组合会提示，注册或持久化失败保留原设置。重启后重新注册保存的组合，如届时被占用则显示未启用，其他成功项继续工作。可从边缘入口或托盘打开设置修复。不会自动监听剪贴板变化或模拟复制。

数据位于 `%LOCALAPPDATA%/LingoSofa`。旧版 DeepSeek 密钥无需重填；没有保存过模型选择时继续默认使用 `deepseek-flash`。默认模型独立保存，语言与置顶设置保持原值。切换默认模型会结束当前模型会话，后续翻译、Ask 和压缩使用所选模型；未发送的输入草稿保留。移除凭证仅删除该服务商的加密凭证并停止 worker，其他服务商凭证和用量历史保留；若移除了默认模型的凭证，需重新配置或选择另一个已配置服务商，不会静默回退。卸载不代表已确认清除数据；完全清理时先退出应用，再删除上述目录。旧助手、W0 和浏览器数据不自动导入。
