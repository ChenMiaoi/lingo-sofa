# 浏览器手动验收步骤

本清单规定 Windows 浏览器正文选区的人工检查步骤。兼容状态见 [兼容与验收状态](acceptance.md)；页面能加载或通用回归通过，不能代替系统选区验收。

## 准备

1. 退出旧 LingoSofa，从待验安装包启动应用，在设置中配置自己的 DeepSeek 账户。记录安装包的 SHA-256。翻译和 Ask 会产生真实调用；不要使用含隐私或凭证的网页。
2. 在 Chrome 打开随仓库提供的 [浏览器样文](../tests/fixtures/browser-selection.html)。可从资源管理器把该 HTML 拖入 Chrome，不需要本地服务器、扩展或登录。测试前记录应用版本、Chrome 版本、Windows 版本、显示器缩放及是否有影响页面的扩展。
3. 使用鼠标选择指定的一段正文，**不要 Ctrl+A 全选页面**。普通阅读不会自动调用模型，按 Alt+Shift+S 才触发选区翻译。

## 必测场景

| 编号 | 操作                                                                                                     | 通过标准                                                                                    |
| ---- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| B1   | 只选中首段 `The browser project code is BIRCH-562...`，按 Alt+Shift+S                                    | 浮层显示对应译文且保留 BIRCH-562；不含相邻 `NOT_SELECTED_GUARD`；原网页位置不变             |
| B2   | B1 完成后，在浮层以外向下滚动网页                                                                        | 确认原文确实移动；译文收起，仅剩边缘入口。到达滚动边界而正文没移动不计验证                  |
| B3   | 滚回顶部，重新选择首段翻译，点击桌面浮层的 Ask，展开“已选文字”                                           | 来源为当前 Chrome 窗口；原文只有选中段落，不含标题、邻段、URL 或用户名                      |
| B4   | **在 LingoSofa 的 Ask 输入框中**输入 `What is the browser project code? Return only the code.`，按 Enter | 回答 BIRCH-562；提交后输入清空；空 Enter 不重复生成；用量有回传                             |
| B5   | Ask 保持打开，在网页区域再次滚动                                                                         | Ask 保留冻结原文和回答，不抢回来源焦点；Esc 回动作列表，再 Esc 返回边缘入口，不恢复失效锚点 |
| B6   | 回顶部，只选中嵌套面板首段 `The nested panel code is WILLOW-908...` 后翻译                               | 新原文与译文使用 WILLOW-908，不串用 BIRCH-562                                               |
| B7   | 在有边框的嵌套面板内部滚动，使选中文字实际移动                                                           | 译文收起；不能只监测页面滚动而漏掉内层滚动                                                  |
| B8   | 重新选择内层首段翻译并 Ask：`What is the nested panel code? Return only the code.`                       | 回答 WILLOW-908，展开原文确认没有之前的 BIRCH-562                                           |
| B9   | 点击网页空白取消选区，再按 Alt+Shift+S                                                                   | 提示没有选区或无法定位，不翻译整页，不显示旧译文                                            |
| B10  | 选中首段复制，按 Alt+Shift+T                                                                             | 明确标为剪贴板独立浮层；不假装知道来源段落位置                                              |

若 B1 或 B6 失败，先记录原提示、当前焦点和截图；不要靠复制粘贴、禁用安全检查或更换为输入框来把“正文划词”记成通过。可以另测剪贴板降级，但要分开记录。

## 统一输入面板

从托盘或边缘菜单打开“输入翻译”。预期复用 Ask 的深色面板，支持多行粘贴，显示“翻译这段文字”和“作为新问题提问”。Enter 执行当前动作，Shift+Enter 换行，Alt+↑↓ 切换动作；真实中文输入法选词确认时不能误提交。

选择翻译应在同一面板展示结果，允许继续追问；新输入或新问题都不应引用此前的 BIRCH-562 / WILLOW-908。测试此项应另记结果，不能替代 B1–B9 的网页正文选区验收。

## Discord 的严格边界

需要重测 Discord 时，只选择已有消息正文并按全局快捷键；问题只输入 **LingoSofa 窗口**。严禁发送 Discord 消息，也不回复、转发、添加反应或向消息输入框粘贴样文。不要点击旧 Vencord 插件的翻译/Ask 按钮来代替本桌面应用测试。
