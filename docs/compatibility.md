## 已选择的真实验收模型与价格

用户已选择官方当前 Flash：provider `deepseek`、API 模型 `deepseek-flash`、端点 `https://api.deepseek.com`，对应 DeepSeek-V4.1-Flash。旧 V4 Flash 标识已转到当前版本，验收不能记为原 V4。[官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)（2026-10-14 核对）。

Pi 1.2.0 目录的 `cost` 有 input/output/cacheRead/cacheWrite，单位为 USD / 百万 tokens。当前 Flash 的 input 0.30、output 1.20、cacheRead 0.006 与官网峰时价格一致；cacheWrite 为 0，官网未单列缓存写入费率。

| 计费桶             | 官方峰时 | 官方谷时 | 当前 Pi 目录 |
| ------------------ | -------- | -------- | ------------ |
| 输入（未命中缓存） | 0.30     | 0.15     | 0.30         |
| 输入（命中缓存）   | 0.006    | 0.003    | 0.006        |
| 输出               | 1.20     | 0.60     | 1.20         |

官网峰时为周一至周五 UTC 01:00–04:00、06:00–10:00，排除中国公共假日；其他时间按谷时收费。Pi 静态目录不包含这套时段和假日规则；LingoSofa 现在根据请求开始时间应用官方峰/谷费率，按 Asia/Shanghai 民用日期识别 2026 年放假安排（含调休假期），周末补班仍按周末谷时处理。日期来源为 [国务院办公厅通知（北京市政府转载）](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。未覆盖年份的工作日峰时窗口按峰时上限保守估算，窗口外及周末仍能确定为谷时。

每条用量保留价格来源、核对日期、采用的单价及请求开始时间；浏览器与 Discord 明细显示来源和峰/谷状态。跨时段请求按开始时间估算，预算预留始终按峰时上限。SDK 会话费用累计各回合快照，而非采用创建会话时的固定单价。历史记录不按新价格回算；旧记录没有快照时注明未保存来源。这些金额不代表供应商实扣；不在运行时抓取网页自动改价。自定义单价仍须由用户明确配置，变更前核对官方来源。真实请求的 usage、思考流与余额查询已通过 [本机验收](real-provider-acceptance.md)；供应商账单实扣仍未对账。

## 翻译结果用量字段升级

翻译响应的每条 result 新增可选 `billing`：请求/缓存来源、实际请求的段落数、总 Token、USD 估算费用和价格快照。字段由服务生成，不接受模型生成的计费声明；缓存结果必须为本次零用量、零费用。新前端接受旧服务缺少该字段，并显示未知。

旧 MV3/严格校验的协议消费者无法识别新增字段，需同步更新 Bridge、浏览器扩展与 Vencord 插件，然后刷新客户端。Native Host 仅转发响应帧，无新增权限或凭据字段。保留协议请求版本 1，升级不改变请求字段、来源隔离、用量历史格式或预算记录；部署不支持新 Bridge 配旧严格响应校验器。

## 数学排版兼容性

固定 KaTeX 0.19.0，输出原生 MathML，无字体/CDN 或新网络权限。Chrome 内容脚本加载器会拒绝公式词法器使用的 U+FFFF 非字符；构建通过 Rolldown `output.minify.codegen.asciiOnly` 将字符写成转义形式，并在扩展审计中拒绝非法 UTF-8、NUL 和 Unicode 非字符。实际 MV3 加载、公式与恢复回归重新通过，保留这一构建要求。
