# 会话历史、思考与工具

翻译与 Ask 使用随包 OMP 的文件会话，消息、模型上下文、压缩记录、服务商返回的思考内容、工具调用及结果由 OMP SessionManager 保存。LingoSofa 将原文与来源作为会话自定义元数据保存，不另外维护一套完整对话数据库。凭证仍保存在独立的加密 vault 中。

## 历史与恢复

- 输入 `/resume` 或点击“会话历史”打开列表；`/history` 是别名。
- 输入标题或会话 ID 搜索全部本机历史，↑↓ 选择，Enter 恢复，Esc 返回原输入草稿。`/resume 搜索词` 可提前填写搜索内容。
- 列表分批读取；Tab 可聚焦“加载更多会话”，Enter 加载下一批，再回到搜索框继续选择。
- 恢复会重建完整的 OMP 上下文，保留消息、压缩记录与原文；旧来源窗口的选区锚点会失效，不再移动或依赖旧窗口。
- `/new` 停止当前任务、保留旧会话文件，并打开空白输入。新输入提交时创建新的 OMP 会话；重启不会自动打开 `/new` 之前的旧会话。
- 正常退出时刷新会话文件。再次启动停留在空闲边缘入口，不自动打开 Ask 或载入上次原文；账户、模型与偏好仍保留。需要继续旧会话时通过 `/resume` 主动选择恢复；不会自动重新发送中断的模型请求或重新执行工具。
- 恢复失败时可通过 `/resume` 重试；会话所用服务商仍须配置凭证。删除凭证不会删除会话正文。

Ask 将本轮提问、思考、工具和回答放在同一阅读区域，追问框固定在底部；复制回答、压缩会话和返回动作收进右上角“会话操作”菜单，Tab 聚焦、Enter 打开，Esc 关闭菜单并保留草稿。回答以 Markdown 显示标题、列表、代码和表格；原始 HTML 不执行，图片只显示替代文字，链接显示地址供复制。回答区的“会话记录”用 Tab 聚焦、Enter 或空格切换，选择“当前回答”返回。界面显示最近 16 条消息摘要，单条过长时明确标示截断，超长原文和回答恢复时也会显示带截断标记的摘要；模型恢复使用完整会话，不受显示摘要长度影响。当前没有历史删除、导入和导出界面。

## 思考

`/thinking off|minimal|low|medium|high|xhigh|max` 设置思考强度。支持的实际档位与输出格式由所选模型、服务商及 OMP 决定；界面展示服务商实际返回的思考文本或摘要，不生成额外的“思考过程”。设置保存在本机，生成或压缩时须先停止任务再修改。可用 Tab 聚焦回答区的“思考过程”并展开查看。

## 工具调用

默认关闭工具。输入 `/tools on` 开启 Ask 中的 OMP 文件读取、搜索、写入、编辑和命令执行工具；`/tools off` 关闭。翻译任务始终不启用工具。项目扩展、MCP、LSP、Skills、自动学习和长期记忆仍未开放。

每次实际执行工具前，会显示工具名、参数与工作目录。焦点落在“拒绝本次”，Enter 拒绝；Tab 移至“允许本次”，Enter 才允许本次执行。没有“始终允许”；重复确认、过期确认及其他会话的确认均不能重用。等待超过 5 分钟、停止任务或退出会话时确认失效。模型会收到拒绝结果。

工具在本机以当前用户权限执行，工作目录是 LingoSofa 数据目录；参数可能指定其他文件或命令。确认前应检查展示的参数。工具结果会进入当前模型上下文，并随 OMP 会话保存在本机。每次工具调用合并为一行名称、路径或命令和状态，结果默认显示短预览；Tab 聚焦对应调用、Enter 或空格展开完整参数与显示结果。思考内容用较弱的文字显示并默认收起。历史调用保留在会话记录中。

## 用量与花费

底部状态栏常驻显示模型、思考档位、当前会话输入/输出 Tokens 与费用估算；没有用量时显示“费用待结算”，缺失价格显示“费用未知”。用 Tab 聚焦“用量与费用”并按 Enter 打开明细，查看思考、缓存、工具调用、当前会话与累计费用，以及未知用量；Esc 先关闭明细并保留追问草稿。正常生成、工具循环中的每次模型请求及压缩均通过同一用量账本计量。

API Key 调用使用 OMP 模型目录及响应中的用量计算美元估算；这是估算，不能代替供应商账单。订阅账户、目录无价格、旧版账本记录、取消或中断且没有用量的调用单列未知，不按零费用处理，也不从 Tokens 推算订阅剩余额度。账本保存费用估算，重启后保留。

## 数据目录

- macOS：`~/Library/Application Support/LingoSofa/`
- Windows：`%LOCALAPPDATA%\LingoSofa\`

`sessions/` 下保存 OMP JSONL 会话，`sessions/current.json` 只记录当前会话 ID；会话文件包含正文及工具数据，不采用凭证 vault 的加密格式。`settings.sqlite` 额外保存思考与工具偏好；`usage.sqlite` 保存无正文、无凭证的用量与已知费用估算。备份和清理时先退出应用。更多数据处理说明见[隐私说明](privacy.md)。
