# 隐私与安全默认值

## 内容发送

手动翻译只处理当前页正文块或过滤后的选区。自动模式仅针对用户在悬浮面板开启的网站/频道，以可见内容优先；扩展不读取其他标签页正文。表单、密码输入、隐藏/编辑区域、导航和独立代码块默认排除。网页模型密钥留在扩展后台，不进入 content script。

正文是模型请求中的不可信数据，不升级成系统指令；模型输出只能作为文本呈现，不执行 HTML，不自动加载链接、附件或远程资源。问答先展示发送范围，用户发起提问后才发送；刷新/跳转需要重新预览。Discord 问答仅带指定消息，不读取频道历史或附件。草稿仅预览/复制，不自动发送。

## 凭证与权限

浏览器 API Key 只存 trusted-context session storage，浏览器关闭后清除；扩展页面提供清除入口。模型端点及自动网站使用可选权限，手动网页使用 activeTab。更换密钥清除旧账户余额缓存；切换端点/provider 清除旧密钥，停用网站自动翻译保留网页访问权限和悬浮入口；用户在 Chrome 撤销网页权限后取消该网站任务、恢复原文并移除入口，其他已授权网站不受影响；设置改变会停止旧任务。Bridge 模式不要求无用的浏览器模型端点权限。

扩展存储不是硬件密钥保险箱。Bridge 密钥来自环境，Pi CLI 认证文件复用需要显式开启；配对文件是本机敏感文件。Bridge 默认目录权限 0700，初始化的配置、配对及用量文件在 POSIX 下为 0600；Windows 需要依赖用户账户和目录 ACL，不能声称 POSIX mode 构成 Windows 的保护。

Bridge 只绑定 loopback，校验短期令牌、来源与 Host，并限制流量和请求长度。不要将其通过公网隧道或反向代理公开。配对令牌暴露时应重新配对并重启服务。

## 记录与保留

| 数据                   | 默认位置与生命周期                         | 可选持久化                               |
| ---------------------- | ------------------------------------------ | ---------------------------------------- |
| 浏览器密钥             | trusted session storage                    | 不支持同步或长期保存                     |
| 网页/消息及译文缓存    | 当前执行进程内存，最多 500 个成功结果      | 首版无正文持久缓存                       |
| 翻译/问答会话内容      | 当前后台/Bridge 的内存会话，最多 50 个会话 | SDK 使用内存会话，不写正文日志           |
| 浏览器用量与在途检查点 | trusted session storage，仅元数据          | 开启后用量写 local storage，保留 1–90 天 |
| Bridge 用量            | 进程内存，仅元数据                         | 开启后写 usage.json，保留 1–90 天        |
| Pi 模型缓存            | Bridge 目录内 model-cache.json             | 模型描述，不是用户正文或问答日志         |
| 配对信息               | Bridge pairing.json，短期令牌              | 文件保留但令牌会过期                     |

用量元数据包括 requestId、隔离 scope、provider/模型、状态、时间、tokens、费用、会话标识、调用用途和速度，不含正文、译文或密钥。scope 中的 tab/频道/账号标识本身也属于需保护的本地元数据。共享统计 `shareUsage` 默认关闭；开启后，同一 Bridge 的配对前端可看到跨端用量元数据，会话正文仍隔离。本地预算机制已移除，旧预算配置被兼容读取但不执行。

浏览器“清除缓存、会话与用量”清理当前扩展，Bridge 模式还清理该扩展来源的 Bridge 状态。其他前端不受正文清理影响。清理前取消在途任务，但晚到的已消费用量仍可能被记录；清理不撤销供应商账单。Discord “清理”清除插件本地译文与令牌，问答的新建/清理按钮清理对应 Bridge 会话；关闭 Bridge 或删除本地配置目录用于进一步清理。

今日/月度展示只覆盖可观测记录；未启用历史时明确仅当前会话可用。统计无法覆盖同一 API Key 在其他应用中的费用。取消、断线、后台退出不保证供应商停止计费；未知消耗不会自动重放或当作 0。

## 当前限制

Pi SDK 的空工具配置不能阻止供应商收到用户主动发送的内容，也不是本机沙箱。页面 CSS/布局和非标准编辑控件可能需要额外适配；跨域 iframe、封闭 Shadow DOM、PDF/OCR 不在已验收范围内。真实客户端安装、账号与许可决策见 [验收记录](acceptance.md)。

网页悬浮入口默认开启，但首次网页访问必须经 Chrome 的权限确认。首次安装及扩展页面提供引导；授权访问不会发送正文。悬浮窗口的自动翻译开关就是当前网站的翻译同意，不再要求额外的应用确认；Chrome 自身的可选权限规则仍适用，见 [官方权限 API](https://developer.chrome.com/docs/extensions/reference/api/permissions)。

连续翻译会话会将同一页面/频道内已经授权的历史作为参考，再次发送给相同供应商；Pi 压缩也需要将该范围历史发送给该供应商生成摘要，并计入用量。不同页面实例、账号/频道及 Ask Pi 不混用历史。暂停自动翻译不会清空历史；会话清理、切换供应商/模型、服务退出会清理相应状态。历史和压缩摘要只保留在内存，不写入 model-cache.json 或用量日志。浏览器 URL 查询参数仅以摘要参与页面隔离，不在用量 scope 中保存原值。

OpenAI 订阅登录使用 Pi 的 OAuth 浏览器流程。访问/刷新凭据仅保存于 Bridge 私有目录的 `oauth-auth.json`，稳定设备标识位于 `oauth-device-id`，文件权限为 0600；两端仅接收连接状态和授权链接。账号重新登录/退出清理旧上下文，但不会删除已消费用量。退出仅清除本机凭据，不声称远端授权已撤销，见 [OAuth 说明](oauth.md)。
