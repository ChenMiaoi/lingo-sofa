# 桌面版数据与模型请求

正式桌面只在用户主动取选区、翻译、提问、压缩或按翻译快捷键时处理任务。Alt+Shift+T 读取当次剪贴板文本，不持续监视剪贴板。macOS 可主动框选截图 OCR，Windows 截图 OCR 尚未开放。

macOS 截图由原生辅助进程交互式框选，Apple Vision 在独立本机进程识别中英文；不自动截屏、监视页面或上传图片。截图与识别输出短暂保存在应用缓存的仅当前用户可访问目录，完成、失败、取消、超时或正常退出后删除，异常退出遗留在下次截图前清理。“截图翻译”、OCR 快捷键和 `/ocr` 都是主动翻译请求；框选完成后识别文字会自动发送给默认模型并按普通会话持久化。详见[macOS 截图识别](macos-ocr.md)。

Alt+Shift+S 启动临时 UIA 助手，读取当前前台应用的非密码选区、选区矩形和来源窗口标题。选区最长 15000 字节，不支持时明确失败，不回退到整篇文档。助手每 150ms 检查该选区和窗口几何，直到收起、切换任务、失效或退出；不会在空闲时监视其他窗口。来源标题和矩形用于本机提示与定位，不进入模型提示；选区正文会在自动开始翻译时发送给所选默认模型的服务商。

翻译、追问和压缩将对应内容及所需会话上下文发送至所选默认模型在 oh-my-pi 目录中的服务地址，使用用户为该服务商保存的 API Key 或订阅授权。服务商与模型列表读取随包 SDK 目录，不会为了加载设置而向所有服务商发送请求。切换默认模型会结束当前会话，后续任务使用新模型；没有静默跨服务商回退。供应商的数据处理以其条款为准。取消不能保证上游停止计费。

API Key 经 Tauri 命令交给 Rust，订阅授权通过 SDK 登录取得并经私有管道交给 Rust；二者均在 `credentials.sqlite` 中按服务商独立加密保存（Windows 使用当前用户 DPAPI，macOS 使用本机凭证保护）。前端只保留当前输入的密钥草稿，保存或切换服务商后清空；状态接口不返回密钥。worker 仅通过私有管道取得凭证，不持久化认证明文，不读取其他应用账户。

订阅登录只在用户启动登录时访问所选服务商的授权接口。浏览器 OAuth 交给系统浏览器，回调与 state 由 SDK 校验；需要浏览器会话的流程使用独立隐私窗口，Cookie 仅由 Rust 传回 SDK，主界面不读取 Cookie 或令牌明文。SDK 的其他应用账户借用关闭。授权及刷新令牌加密保存在同一 vault，刷新写入先经过 Rust 确认，不记录授权码；登录交互提示可能包含服务商要求的设备码。详细流程与验收边界见[订阅登录指南](subscription-login.md)。

`%LOCALAPPDATA%/LingoSofa/settings.sqlite` 保存语言、置顶和默认服务商/模型标识，`shortcuts.sqlite` 保存全局快捷键组合（含译文样式切换与 macOS OCR）；原文、来源、会话消息、压缩记录及服务商返回的思考与工具数据由 OMP 以 JSONL 保存在同目录的 `sessions/`，这些会话文件未采用凭证 vault 加密格式；未发送草稿仅在内存。macOS 数据根为 `~/Library/Application Support/LingoSofa/`。快捷键组合只用于本机注册和显示，不发送给模型。`usage.sqlite` 保存调用标识、状态、供应商用量，不记录正文/密钥，并保存可确定的 SDK 美元费用估算；订阅和缺失价格单列未知。当前尚无关闭/清除用量历史的界面。未知和部分用量单列，不等于零消耗，不估算金额。

输入框中的 `/settings`、`/model`、`/language`、`/pin`、`/new` 等配置和导航命令只在本机处理；`/login`、`/subscribe` 通过 SDK 连接所选服务商的授权接口，未知或错误命令也不会发送给模型。以 `//` 开头的正文作为普通文本提交，会遵循对应翻译或提问的发送路径。

应用更新默认在启动后及每 6 小时访问本仓库 GitHub Releases 获取版本信息，可在“设置 → 关于与更新”关闭。请求包含应用 User-Agent 和网络连接必需的信息，不包含原文、草稿、模型凭证或用量。仅用户点击下载时获取安装包，通过签名校验后才允许手动安装重启。更新开关保存于本机 `updates.sqlite`，下载包仅保留在进程内存，退出后丢弃；更新失败不自动下载重试。详见[应用更新](updates.md)。

工具默认关闭；`/tools on` 开启 Ask 工具，每次执行前展示工具名、参数和工作目录并要求用户单次确认。工具可读写本机文件或执行命令，结果会发送给当前模型并持久化到会话。`/resume` 恢复本机完整上下文；启动可继续上次会话，不自动重发请求或执行工具。思考、费用及键盘操作见[会话指南](sessions.md)。

应用没有遥测、自动上传日志、失败请求自动重试。开发前端使用本机服务，安装版不运行 HTTP Bridge。真实验证命令只有明确调用时才读取开发 `.env`，不属于桌面自动导入流程。
