# 桌面版数据与模型请求

正式桌面只在用户主动取选区、翻译、提问、压缩或按翻译快捷键时处理任务。Alt+Shift+T 读取当次剪贴板文本，不持续监视剪贴板；当前没有截图/OCR。

Alt+Shift+S 启动临时 UIA 助手，读取当前前台应用的非密码选区、选区矩形和来源窗口标题。选区最长 15000 字节，不支持时明确失败，不回退到整篇文档。助手每 150ms 检查该选区和窗口几何，直到收起、切换任务、失效或退出；不会在空闲时监视其他窗口。来源标题和矩形用于本机提示与定位，不进入模型提示；选区正文会在自动开始翻译时发送给 DeepSeek。

翻译、追问和压缩将对应内容及所需会话上下文发送给 DeepSeek 官方 API，使用用户自己的账户；模型目录核验也访问 DeepSeek。供应商的数据处理以其条款为准。取消不能保证上游停止计费。

API Key 经 Tauri 命令交给 Rust，以当前 Windows 用户的 DPAPI 加密保存于 `credentials.sqlite`。前端只保留未保存草稿，保存后清空；状态接口不返回密钥。worker 仅通过私有管道取得凭证，不持久化认证明文，不读取其他应用账户。

`%LOCALAPPDATA%/LingoSofa/settings.sqlite` 保存语言和置顶，`shortcuts.sqlite` 保存三项全局快捷键组合；原文、译文、会话仅在内存。快捷键组合只用于本机注册和显示，不发送给模型。`usage.sqlite` 保存调用标识、状态、供应商用量，不记录正文/密钥；当前尚无关闭/清除用量历史的界面。未知和部分用量单列，不等于零消耗，不估算金额。

应用没有遥测、自动上传日志、失败请求自动重试。开发前端使用本机服务，安装版不运行 HTTP Bridge。真实验证命令只有明确调用时才读取开发 `.env`，不属于桌面自动导入流程。
